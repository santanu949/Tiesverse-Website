# Tiesverse Website

## 📌 Project Overview
Tiesverse is a simple static website created using **HTML, CSS, and JavaScript**.  
The project was built to understand the basics of front-end web development, including page structure, styling, and basic interactivity.

This website demonstrates how individual web technologies work together to create a complete user-facing application.

## 🛠️ Technologies Used
- **HTML5** – For structuring the web pages  
- **CSS3** – For styling, layout, and responsiveness  
- **JavaScript** – For basic interactivity and dynamic behavior  

## 🎯 Features
- Clean and simple user interface  
- Responsive layout using CSS  
- Basic JavaScript functionality for interaction  
- Multi-section webpage design  


## 🚀 How to Run the Project
1. Download or clone the repository  
2. Open `index.html` in any modern web browser  
3. No additional setup or dependencies required  

## 📚 Learning Outcomes
- Understanding HTML page structure  
- Applying CSS for styling and layout  
- Using JavaScript for DOM manipulation  
- Building a complete front-end website from scratch
